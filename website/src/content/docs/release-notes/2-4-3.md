**Released:** 2026-06-15

Kure Monitor 2.4.3 focuses on UI and branding updates, as well as keeping our supported AI providers completely up-to-date with their latest model releases from the 2026 cycle.

**No breaking changes. No API changes. No DB migrations.**

## What's new

### UI Branding Updates
Replaced the default frontend icons with the official Kure Monitor logo in the dashboard and login screens. The documentation website was also updated to include the logo and aligned to a matching purple color theme.

### LLM Upgrades
Updated the default LLM provider options across the board to their latest 2026 release models:
- **Anthropic**: Added support for `claude-fable-5`, `claude-sonnet-5`, and `claude-opus-4-8`.
- **Google Gemini**: Added support for `gemini-3.1-pro`, `gemini-3.5-flash`, and `gemini-3.1-flash-lite`.
- **Groq (Meta Llama)**: Shifted default to `llama-4-scout` and added `llama-4-maverick`.
- **OpenAI**: Updated to the `gpt-5.6` series (Sol, Terra, Luna).
- **Ollama**: Defaulted options to newer Llama 4 locally run equivalents.
## Upgrade

### Helm

```bash
helm repo update
helm upgrade kure-monitor kure-monitor/kure \
  --namespace kure-system \
  --version 2.4.3
```

No values changes are required. The new models are available in the LLM Settings tab for administrators.

### Verifying the upgrade

1. Open the UI, you should immediately see the new Kure Monitor logo in the header instead of the generic server icon.
2. Go to **Admin → LLM Settings**.
3. Cycle through the providers (OpenAI, Anthropic, Gemini, Groq, Ollama, Copilot) and confirm the latest 2026 models are available in the dropdowns.
