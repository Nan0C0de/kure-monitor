Kure Monitor 2.4.5 brings a brand new way to consume AI observability by introducing the official Grafana App plugin, alongside major SEO improvements and documentation restructuring.

## Grafana App Integration

Kure Monitor now ships with a dedicated Grafana App plugin (`kuremonitor-kure-app`)! 
You can now bring the proactive AI troubleshooting chat, failure feed, and AI Advice directly into your existing Grafana observability dashboards. 

See the new [Grafana Integration](/integrations/grafana/) guide for installation instructions.

## Custom Domain & SEO Expansion

- **New Domain**: Migrated all official documentation, Helm charts, and plugin metadata to the new custom domain: `https://kuremonitor.com`.
- **Error Debugging Guides**: Created deep-dive error troubleshooting guides (e.g. CrashLoopBackOff, OOMKilled, ImagePullBackOff) to help users debug faster via organic search.
- **Helm Descriptions**: Updated Helm chart and ArtifactHub metadata to reflect Kure Monitor's evolution into a full AI observability platform, highlighting all four core pillars (AI Advice, Security Scanner, Diagram, and Pod Monitoring).

## Documentation Overhaul

- Introduced a new **Integrations** section in the documentation sidebar.
- Cleaned up legacy markdown files (`docs/`) to keep the Astro Starlight site clean and focused.
- Re-ran URL canonicalization across the entire documentation site to ensure all Markdown links point to the new domain structure without 404s.
